Patch Notes

For Linux Users:

Run this command to download XMRig AUT from the source:

https://raw.githubusercontent.com/JacksonZenisek/XMRig-AUT/refs/heads/main/XMRigAUT/xmrig_automation_utility_toolAUT.sh


For Windows Users:

Open PowerShell as administrator and run this command to install Linux Ubuntu within PowerShell:

wsl --install

Create your account, then restart your PC. Once your PC has booted back up, open PowerShell and run this command to start Linux Ubuntu:

wsl

Once Linux Ubuntu has started in PowerShell, run this command to download XMRig AUT form the source:

wget https://raw.githubusercontent.com/JacksonZenisek/XMRig-Automation-Tool/refs/heads/main/xmrig_automation_utility_tool(AUT).sh


Download XMRig AUT:

Optionally if you're running a GUI version of Linux, you can download XMRig AUT and place the program in the folder that you want.
