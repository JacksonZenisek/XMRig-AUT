Welcome to the XMrig Automation Utility Tool website!

XMRig AUT is designed to make the use of XMRig more user-friendly, and to make XMRig tasks more convienent for the user.

The developer, Jackson Zenisek, orchestrated all scripts needed to install XMRig, run XMRig, and generate new wallet keys, so that the process of cryptomining XMR can be easy-going.

This program is free to install and use as he believes that everyone should have a chance to successfully mine XMR.
